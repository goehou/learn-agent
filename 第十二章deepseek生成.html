1 本章要掌握的目标
  • 五个任务工具从同一 ToolDefinition 生成 schema 与 handler。
  • Task 三态单向推进 pending→in_progress→completed。
  • 阻塞是派生事实：pending 且至少一个依赖未完成。
  • 全图排他锁包住加载、DAG 校验、条件迁移与原子 JSON 替换。
  • claim 只有一个并发赢家，complete 只能由 owner 执行；重建严格恢复。
2 核心知识点
TODO 与 Task 不是一回事

todo_write 是当前会话步骤快照（进程内存）；JSON Task DAG 是可独立认领完成的项目任务（磁盘持久化、有依赖）。

维度      todo_write           JSON Task DAG
粒度      当前工作的步骤快照    可独立认领的项目任务
所有者   单个 Agent session  当前 workspace
存储     进程内存             .agent_tutorial/.tasks/{uuid}.json
依赖     无                  blocked_by 有向边
一个 Task 的严格模型

id 是 canonical UUID，文件名必须与 payload ID 相同；subject 非空；blocked_by 是 canonical UUID 且不重复；pending 必须 owner===null；in_progress/completed 必须有非空 owner。

const task = new Task({
  id, subject, description,
  status: TaskStatus.PENDING,
  owner: null, blockedBy: [],
});
为什么锁的是整张图

claim 的判断依赖所有 blocked_by 任务；create 要验证全图缺边与环。只锁单个文件无法把『读取依赖→判断→写入』做成原子决策。

async #withLock(paths, operation) {
  const release = await acquireFileLock(paths.tasks, {
    lockfilePath: paths.lock, realpath: true,
    stale: 30_000, update: 10_000, retries: 0,
  });
  try { return await operation(); }
  finally { await release(); }
}
原子 JSON 替换

临时文件 + wx 创建 + write + sync + rename 原子替换。失败时旧文件保持原字节，UUID 碰撞绝不覆盖旧任务。

const temporary = join(dirname(path), `.${randomUUID()}.tmp`);
handle = await open(temporary, "wx");
await handle.writeFile(content);
await handle.sync();
await handle.close();
await rename(temporary, path);
owner 不能由模型参数伪造

claim_task schema 只有 task_id；owner 来自 ToolContext.identity。额外字段会在副作用前被 schema 拒绝。

const task = await store.claimTask(
  input.task_id, normalizeOwner(context.identity));
3 机制流程
1
create_task

subject/description/blocked_by；锁内验证 ID 碰撞、依赖存在、无自依赖、全图无环。

2
claim_task

pending → in_progress，owner 来自 identity，条件迁移。

3
complete_task

in_progress + owner 匹配 → completed，返回本次直接解锁集合。

4
重建

锁内重读全部 JSON，完整校验；坏文件/缺边/环明确失败。

4 术语表
TaskStatuspending / in_progress / completed 三态。
blocked_by依赖边；blocked 是派生事实而非第四种状态。
canonical UUID规范 UUID 文本，映射为文件名。
TaskStorageError持久化文件或目录边界损坏。
全图锁串行化所有读改写，保证原子决策。
